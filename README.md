# TENEND ONLINE

Online Action RPG บนเว็บ (HTML5 Canvas + Node.js WebSocket) • มุมมอง Top-down 3/4 • กราฟิก Pixel Art (วาดด้วยโค้ดทั้งหมด ไม่ต้องใช้ไฟล์ภาพ)
แนวฟาร์มของแบบ Ragnarok + Build แบบ ARPG + PvP + Guild War

```bash
npm install
npm start            # http://localhost:8080
npm test             # integration test แบบ headless (เล่นวนลูปหลักทั้งหมดอัตโนมัติ)
```

ตัวแปรแวดล้อม (Environment)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | 8080 | พอร์ตเซิร์ฟเวอร์ |
| `DATA_DIR` | `./data` | ที่เก็บฐานข้อมูล JSON |
| `PVP_BOT_FILL` | 25 | วินาทีที่รอในคิว PvP ก่อนเติมบอทฝึกซ้อม (แมตช์ที่มีบอทจะไม่นับ Ranked) |
| `RAID_MIN_PLAYERS` | 4 | จำนวนผู้เล่นขั้นต่ำของ Raid (ตั้งเป็น 1 ไว้ทดสอบ) |
| `GUILDWAR_MIN` | 1 | จำนวนขั้นต่ำต่อฝั่งของ Guild War ก่อนเติมบอท |
| `GM_ACCOUNTS` | - | รายชื่อบัญชี GM คั่นด้วยจุลภาค เช่น `admin,mod1` |
| `GM_AUTO_FIRST` | เปิด | ถ้ายังไม่มี GM เลย บัญชีแรกที่ล็อกอินจะได้สิทธิ์ GM (เจ้าของเซิร์ฟเวอร์) ตั้ง `0` เพื่อปิด |
| `DEV` | - | `1` = เปิดคำสั่งทดสอบให้ทุกบัญชี (ห้ามเปิดบนเซิร์ฟเวอร์จริง) |

## ปุ่มควบคุม

- คลิกซ้ายที่พื้น = เดินไปจุดนั้น (A* หาทางให้) • กดค้างลาก = เดินตามเมาส์ • WASD = เดินเอง • คลิกมินิแมพ/แผนที่ = เดินไปที่นั่น
- คลิกมอนสเตอร์ = ล็อกเป้าแล้วตีด้วยสกิลลำดับแรก • คลิกขวา = สกิลช่อง 2
- Hotbar 30 ช่อง 3 แถว: `1-0` / `Shift+1-0` / `Alt+1-0` • `R` อัลติเมท • ย่อเหลือ 1 แถวได้ • ลากสกิลจากหน้าต่าง `K` มาวาง, คลิกขวาที่ช่องเพื่อถอด
- `Space` หลบ • `F` Counter • `Q`/`T` ยา • `Z` เก็บของ • `E` คุย NPC • `U` เปิด/ปิดออโต้ • `Y` ตั้งค่าออโต้ • `F9` แผง GM
- เมนู: `I` กระเป๋า • `C` ตัวละคร • `K` สกิล • `N` รูน • `P` Passive • `B` Build • `J` เควสต์ • `O` ปาร์ตี้ • `G` กิลด์ • `V` PvP • `M` แผนที่ • `H` วิธีเล่น • `Esc` ปิดหน้าต่างบนสุด

การเดินทาง: ข้ามแมพได้ทางประตูวาร์ป 🌀 ที่ขอบแผนที่ หรือที่ NPC นักเคลื่อนย้ายในเมืองเท่านั้น (แผนที่ใช้สั่งเดินอย่างเดียว วาร์ปไม่ได้)

## ระบบออโต้ (U / Y)

- เป้าหมาย: ทุกตัว / เลือกชนิดมอนเอง / เฉพาะบอส • ตีบอสก่อน • ไม่ตี Elite • เลือกตัวใกล้สุด/HP น้อยสุด/เลเวลสูงสุด
- พื้นที่: รัศมีรอบจุดเริ่มหรือรอบตัว • เก็บของอัตโนมัติ • ใช้ยาตาม % • หลบพื้นแดงของบอส • กด Counter ท่าสีทอง • ใช้อัลติเมทกับบอส/Elite
- ลำดับสกิล: ดึงจาก Hotbar จัดลำดับก่อน-หลังด้วย ▲▼ และปิดบางสกิลได้ ค่าตั้งเก็บบนเซิร์ฟเวอร์ตามตัวละคร
- ออโต้ทำงานฝั่ง client แต่ทุกการกระทำยังผ่านการตรวจของเซิร์ฟเวอร์ตามปกติ

## ระบบ GM (F9)

ใช้ได้ทั้งบนเซิร์ฟเวอร์ออนไลน์และเวอร์ชันออฟไลน์ ทุกคำสั่งบันทึกใน `db.gmlog`
- ผู้เล่น: รายชื่อออนไลน์ • ไปหา/เรียกตัว • ฮีล ชุบ สังหาร • เตะ • ห้ามแชท • แบน/ปลดแบน • ให้/ถอดสิทธิ์ GM
- ตัวละคร: ตั้งเลเวล • ให้ทอง Honor EXP • สร้างไอเทมทุกระดับ/ครบชุด • วัตถุดิบ รูน ยา • ซ่อม • รีเซ็ต Build • ล้างกระเป๋า • ส่งไปแมพ
- โลก: God mode • ล่องหน • ความเร็ว x0.5–x5 • วาร์ปตัว GM • เสกมอน/Elite/บอส/บอสโลก • ฆ่ามอนทั้งแมพ • ประกาศ • อัตรา EXP/ดรอป/ทอง (อีเวนต์) • จัดการกิลด์
- เซิร์ฟเวอร์: สถิติ (ออนไลน์, instance, unit, หน่วยความจำ) • ตั้งค่าคิว PvP/Raid/Guild War • บันทึกฐานข้อมูล

## สถาปัตยกรรม

```
shared/      โค้ด/ข้อมูลที่ใช้ร่วมกันทั้ง Browser และ Server (ES Modules)
  constants.js  ค่าคงที่ เศรษฐกิจ PvP ธาตุ สถานะ
  classes.js    นิยาม 10 คลาส (สเตต, พาเลตต์, passive ประจำคลาส)
  classkits.js  ชุดสกิลของแต่ละคลาส: 9 สาย × 10 สกิล + อัลติเมท 10 + Class Trait
  skills.js     ตัวสร้าง 1,000 สกิลจาก classkits + ตัวปรับแต่ง (applyMods) + resolveSkill() รวม rank/รูน/keystone/legendary
  runes.js      Support Runes (แต่ละอันคือฟังก์ชันแปลง spec ของสกิล)
  passives.js   Passive Tree แบบ data-driven
  items.js      ฐานไอเทม affix legendary mythic set วัตถุดิบ
  stats.js      คำนวณค่าสถานะ (รวม normalize สำหรับ Ranked PvP)
  world.js      เมือง แมพ มอนสเตอร์ การ์ด บอส ดันเจี้ยน เควสต์
  mapgen.js     สร้างแผนที่แบบ deterministic (client/server ได้ผลเหมือนกัน ไม่ต้องส่ง tile)
server/      Authoritative game server
  index.js      HTTP + WebSocket
  game.js       session, การเคลื่อนที่, ร่ายสกิล, EXP/ดรอป, ตาย/เกิด
  instance.js   จำลองแมพ: AI มอนสเตอร์, AI บอส (telegraph/counter/phase), projectile, area, snapshot
  combat.js     ดาเมจ สถานะ minion totem orbit
  modes.js      ประชากรมอนในแมพฟาร์ม บอสแมพ บอสโลก
  dungeons.js   Story / Abyss / Hunt / Raid / Guild Boss
  pvp.js        คิว จับคู่ Arena/BG/Guild War และบอท
  player.js     Build, ไอเทม, คราฟต์, NPC, เควสต์
  social.js     แชท ปาร์ตี้ กิลด์ ตลาด
  loot.js       ตารางดรอป (เซิร์ฟเวอร์เท่านั้น)
client/      index.html + js/ (main, render, sprites, ui)
```

หลักการสำคัญ: Browser ส่งแค่ **input** (ทิศทาง, ร่ายสกิลช่องไหน, หลบ, เก็บของ) — เซิร์ฟเวอร์เป็นผู้ตัดสินตำแหน่ง ดาเมจ คูลดาวน์ ทรัพยากร ดรอป และการซื้อขายทั้งหมด
Snapshot ส่ง 10 ครั้ง/วินาที เฉพาะสิ่งที่อยู่ในรัศมีมองเห็น (interest management) และ projectile ถูกจำลองฝั่ง client เพื่อลด bandwidth

## VFX (วาดด้วยโค้ดทั้งหมด)
`client/js/fx2.js` — เอนจินอนุภาคแบบ pixel art: ระเบิด (มีเมฆเห็ดเมื่อรัศมีใหญ่), Implosion, วงแหวนไฟ, เสาไฟ, เปลวไฟ/ถ่านไฟ, พายุน้ำแข็ง, ผลึกแช่แข็ง, สายฟ้าแตกกิ่ง (midpoint displacement + กะพริบ), ลำแสงศักดิ์สิทธิ์, น้ำพุ/ละอองน้ำ, ควันพิษ, เงามืด, วงเวทอาร์เคน, Hex Force Field, Disintegrate, Shatter, Respawn Beam, Soul Rise • มีแสงเรืองแบบ additive และ gradient สีต่อธาตุ

### เอฟเฟกต์เฉพาะตัวทั้ง 1,000 สกิล
`client/js/skillfx.js` สร้าง "สูตรเอฟเฟกต์" ให้ทุกสกิลจากความสามารถของสกิลนั้นเอง:
- **ลวดลายประจำคลาส** — นักรบ: รอยฟันและเศษหิน • พาลาดิน: กางเขนทองและเกล็ดโล่ • พรานธนู: ขนนกและใบไม้ • นักฆ่า: มีดบินและควันเงา • จอมเวท: วงเวทผลึกและอักษรรูน • เนโครแมนเซอร์: กะโหลกและดวงวิญญาณ • นักบวช: ปีกขาวและรัศมี • ชาแมน: วิญญาณธรรมชาติ • มือปืน: ประกายปากกระบอกและปลอกกระสุนเด้งพื้น • นักพรต: วงคลื่นปราณและกลีบบัว
- **ตราสัญลักษณ์จากชื่อสกิล** (43 แบบ เช่น Dragon → มังกร, Meteor → ดวงดาว, Heal → หัวใจ, Bullet → กระสุน) ใช้ทั้งเป็นกระสุน ตราตอนระเบิด และเงาตอนพุ่ง
- **วงเวทบนพื้น** จำนวนเหลี่ยม/แบบดาว/จำนวนชั้น/ทิศหมุน ต่างกันทุกสกิล • **รูปแบบการระเบิด** 14 แบบตามพฤติกรรม (เกลียว ฝนตก เสาพลัง กลีบบาน คลื่นซ้อน หลุมแตก ฯลฯ) • **โทนสี** ตามธาตุ เหลื่อมสีเฉพาะสกิล
- **เอฟเฟกต์ตามตัวปรับแต่ง** เช่น แช่แข็ง → ผลึกน้ำแข็ง, ดูด → วังวนเข้าหา, ปลิดชีพ → กะโหลกแดง, ตีตรา → เป้าเล็ง, ดูดเลือด → หัวใจลอย, มึนงง → ดาววน
- ดูคำอธิบายเอฟเฟกต์และกด **▶ ดูเอฟเฟกต์** ได้ในหน้าต่างสกิล • ตรวจว่าไม่ซ้ำกันด้วย `node tools/fxcheck.js`

## สมดุลเกม
`node tools/balance.js` แสดงรายงาน: จำนวนตีต่อมอนสเตอร์ (~2.5–4.8 ครั้งทุกเลเวล), เวลารอดเมื่อสู้ 3 ตัว, เวลาฆ่าบอสสนาม (15–53 วินาที), ดาเมจท่าใหญ่ของบอส (10–18% HP)

> หมายเหตุ: ID สกิลและโหนด Passive เปลี่ยนในเวอร์ชันนี้ ตัวละครเก่าจะต้องใส่สกิลใน Hotbar และลงแต้ม Passive ใหม่

## UI

- ทุกตัวเลือกเป็นไอคอน (ไม่มี dropdown): ช่องอุปกรณ์ ชนิดอาวุธ ตัวเร่ง เซ็ต รูน บอส มอนสเตอร์ แมพ ตรากิลด์ ช่องแชท
- กระเป๋าแบบ Ragnarok: ตัวละครตรงกลาง อุปกรณ์สองข้าง กระเป๋าแบ่งหมวด (ทั้งหมด/อุปกรณ์/การ์ด/ใช้งาน/วัตถุดิบ/รูน) ไอคอนไอเทม pixel art วาดด้วยโค้ด
- แผนที่โลกวาดเป็นภาพ (ภูเขาหิมะ ป่า ทะเลทราย ภูเขาไฟ ชายฝั่ง) คลิกจุดเพื่อดูข้อมูล: มอนสเตอร์ การ์ดที่ดรอป บอส บริการ NPC และแมพที่เชื่อมกัน
- หน้าต่างจัดเรียงข้างกันอัตโนมัติไม่ทับกัน HUD แต่ละส่วนมีตำแหน่งตายตัวไม่ซ้อนกัน

## การต่อยอด

- **เพิ่มคลาส**: เพิ่ม object ใน `CLASSES` (`shared/classes.js`) และชุดสกิลใน `KITS` + `TRAITS` (`shared/classkits.js`) รูปแบบบรรทัด `"ชื่อ|กลไก|ตัวปรับ|ธาตุ"` แล้วรัน `node tools/skillcheck.js` เพื่อยืนยันว่าไม่ซ้ำ
- **เพิ่มกลไกสกิล**: เพิ่ม `S(...)` ใน `shared/signatures.js` (+ ตัวทำงานพิเศษใน `server/sigexec.js` และสไตล์ VFX ใน `client/js/vfx.js` ถ้าต้องการ) คลาสจะเลือกไปใช้ตามความถนัดเอง
- **เพิ่มรูน**: เพิ่ม object ใน `RUNES` พร้อม `apply(spec)` — สกิลเดิมไม่ต้องแก้
- **เพิ่มโหนด Passive**: ต่อท้าย chain ใน `BRANCHES` หรือเพิ่ม branch ใหม่ — ID เดิมไม่เปลี่ยน save เดิมใช้ได้ (โหนดที่ถูกลบจะถูกล้างอัตโนมัติ)
- **เพิ่ม Legendary**: เพิ่มใน `LEGENDARIES` (items.js) และใส่ผลใน `LEGENDARY_SKILL_MODS` (skills.js) หรือใน combat
- **เพิ่มบอส/ท่าบอส**: เพิ่มใน `BOSSES` / `BOSS_ATTACKS` ใน `world.js`
- **เพิ่มแมพ/ภูมิภาค**: เพิ่มใน `REGIONS` ใน `world.js`
- อนาคต: Guild Territory, Castle Customization, สงครามข้ามเซิร์ฟเวอร์, Guild Alliance (มีฟิลด์ `alliance` เตรียมไว้), ย้ายฐานข้อมูลเป็น PostgreSQL/Redis (แทน `server/db.js` โดยคง API เดิม)
